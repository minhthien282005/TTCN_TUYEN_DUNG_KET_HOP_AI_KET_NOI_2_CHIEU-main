# Ketnoi — kết nối tuyển dụng hai chiều

Đồ án nền tảng tuyển dụng thông minh. Yêu cầu Node.js 20 trở lên; chạy từ thư mục gốc bằng `npm.cmd start`, sau đó mở [http://localhost:3000](http://localhost:3000).

Mã và tài liệu [Sprint 1 — Tài khoản, Phân quyền & Hồ sơ Sinh viên](<Sprint 1_ Tài khoản, Phân quyền & Hồ sơ Sinh viên/readme.md>), [Sprint 2 — Doanh nghiệp, Tin tuyển dụng, Tìm kiếm & Kiểm duyệt](<Sprint 2_ Doanh nghiệp, Tin tuyển dụng, Tìm kiếm & Kiểm duyệt/readme.md>) và [Sprint 3 — Pipeline CV, Chuẩn hóa kỹ năng & Vector Embedding](<Sprint 3_ Pipeline CV, Chuẩn hóa kỹ năng & Vector Embedding/readme.md>) nằm trong từng thư mục Sprint. Mở `/jobs.html` để tìm việc, `/employer.html` để quản lý tin nhà tuyển dụng, `/cv.html` để quản lý CV sau khi đăng nhập sinh viên. Trang chủ và dữ liệu runtime dùng chung vẫn ở `public/` và `data/`; lệnh `npm` và cấu hình CI ở root.
