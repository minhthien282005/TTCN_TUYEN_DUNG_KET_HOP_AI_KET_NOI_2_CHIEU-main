# Ketnoi — kết nối tuyển dụng hai chiều

Đồ án nền tảng tuyển dụng thông minh. Yêu cầu Node.js 20 trở lên; chạy từ thư mục gốc bằng `npm.cmd start`, sau đó mở [http://localhost:3000](http://localhost:3000).

Mã, kế hoạch và tài liệu bàn giao Sprint 1 được gom tại [Sprint 1 — Tài khoản, Phân quyền & Hồ sơ Sinh viên](<Sprint 1_ Tài khoản, Phân quyền & Hồ sơ Sinh viên/readme.md>). Trang chủ và dữ liệu runtime dùng chung vẫn ở `public/` và `data/`; lệnh `npm` và cấu hình CI ở root theo yêu cầu của nền tảng.
